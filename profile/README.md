## About

**Summerfall Development** builds paid and free infrastructure for Minecraft networks — plugins, forks, bots, and the web tooling around them. Small footprint, sane defaults, built to actually run in production.

<div align="center">

<img src="https://skillicons.dev/icons?i=java,rust,nodejs,nextjs,js&theme=dark" alt="Tech stack" />

</div>

<br>

## What We Build

| | |
|---|---|
| 🧩 **Velocity / Paper Plugins** | Production plugins for modern proxy & server stacks |
| ⚙️ **Spigot Forks** | Performance-tuned server core forks |
| 🗺️ **Maps** | *Planned* |
| 🤖 **Discord Bots** | Moderation, economy, and network-integration bots |
| 🌐 **Websites** | Storefronts, dashboards, and network sites |
